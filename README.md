# ReportClickup Docs

โครงคู่มือ HTML ภาษาไทยสำหรับ ReportClickup เปิดผ่าน Node.js โดยไม่ต้องตั้งค่า ClickUp หรือ API token

## เปิดคู่มือ

ใช้ Node.js 20 ขึ้นไป

```sh
npm start
```

เปิด [http://127.0.0.1:3000](http://127.0.0.1:3000) หรือกำหนดพอร์ตด้วย `PORT=3100 npm start`

## สถานะเอกสาร

หัวข้อในคู่มือเป็นโครงรอตรวจสอบกับซอร์สและหน้าจอจริง ไฟล์จากโปรเจกต์หลักที่พบในเครื่องยังเป็นไฟล์บนคลาวด์ที่อ่านเนื้อหาไม่ได้ จึงยังไม่มีภาพประกอบและรายละเอียดพฤติกรรมที่ตรวจสอบแล้ว

## ข้อมูลที่ใช้ทำคู่มือฉบับเต็ม

- สำเนาโปรเจกต์หลักที่เปิดอ่านได้ หรือ URL ของซอร์ส พร้อมระบุเวอร์ชันที่ใช้งานอยู่ หากรันระบบไม่ได้ ให้ใช้ภาพหน้าจอจากเวอร์ชันนั้นแทน
- ชุดข้อมูลสำหรับถ่ายภาพที่แชร์ได้ และขอบเขตข้อมูลที่ต้องปิดบัง
- กลุ่มผู้อ่านหลัก เช่น ผู้ใช้รายงานหรือผู้ดูแลระบบ เพื่อกำหนดความลึกของคู่มือ
- กติกาธุรกิจที่ไม่ปรากฏในซอร์ส เช่น นิยามสถานะ สูตร Capacity และวิธีตรวจว่าข้อมูลล่าสุด
